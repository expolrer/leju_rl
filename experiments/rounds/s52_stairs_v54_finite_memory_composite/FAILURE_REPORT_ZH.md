# S52 v54 FiniteMemoryComposite 短预检失败报告

## 结论

v54 的 `32x2` 冒烟和 `128x6` 短预检均正常结束，无 Traceback、NaN、OOM 或 GPU 错误。全部固定 `seed=131` 候选都完成上楼、平台、四级正向下楼和落地，且首次周期零重置；但没有候选通过终点路线与同源净空联合门，因此不启动正式长训练，安全基线继续保留 `model_92150.pt`。

## 本轮改动

- 从受保护 S52 `model_92150.pt` warm-start，重置优化器。
- 分别将同源 clearance cost 除以 `0.10`、impact cost 除以 `0.25`，裁剪到 `[0,1]` 后取较大值。
- 在 frame `800--1258` 使用 `decay=0.85` 的衰减最大值；半衰期约 4.3 个控制步，只跨越短接触窗口，不再整段回填。
- PPO cost budget 为 `0.02`，segment replay scale 降为 `0.25`，PID 增益同步降低。
- 148 维 actor、固定几何、teacher 和原有路线奖励保持不变。

## 训练曲线

- mean reward：`6.6024 -> -2.3196`，峰值 `8.1576 @ 92151`，最低 `-7.8100 @ 92153`。
- mean episode length：`22.0 -> 98.92`。
- policy KL：`4.194e-4 -> 5.602e-4`；teacher KL：`2.936e-5 -> 8.188e-5`。
- value loss：`12.384 -> 2.170`；surrogate loss：`0.000972 -> 0.001941`。
- cost-value loss：`3.177 -> 0.479`，明显低于 v53 的约 `73.54`。
- constraint error：`0.04586 -> -0.00093`。
- finite-memory cost 峰值 `0.12995 @ 92154`，最终 `0.01191`；相比 v53 的 `3.6099`，尺度和振荡明显受控。

## 失败原因与下一步

1. 有限记忆解决了 cost 尺度爆炸，却没有解决下楼结束后的前向/横向终点漂移。
2. 风险约束在下降阶段有效，但终点路线误差的梯度仍来自另一组稀疏奖励；安全与终点目标没有共享明确的未来接触目标。
3. 继续调整 max、tail 或 PID 数值只会重复 v30--v32 与 v53 的失败模式。

下一版不再增加风险记忆长度。应保持 v54 的局部安全约束，转向显式的 future-contact/foothold 条件：在最后一级下楼和落地阶段，按参考未来接触位置与剩余接触时间定义低权重足端目标残差；先作为 reward/critic metric，不改变 148 维 actor，验证是否能减少终点漂移而不侵入摆腿净空。
