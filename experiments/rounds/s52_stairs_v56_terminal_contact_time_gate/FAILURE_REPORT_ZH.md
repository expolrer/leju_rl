# S52 v56 TerminalContactTimeGate 短预检失败报告

## 结论

v56 的 `32x2` 冒烟和 `128x6` 短预检均正常结束，没有 Traceback、NaN、OOM 或 GPU 训练故障。受保护基线及五个候选在固定 `seed=131` 下均完成上楼、平台、四级正向下楼和落地，首次周期零重置。接触时序门改善了部分候选的在线同源净空、平均 cost 和冲击，但没有候选同时通过终点路线与全部安全门，因此不启动正式训练，安全基线仍是独立保存的 `model_92150.pt`。

## 本轮改动

- 回到 v54，而不是继承 v55 的终点位置/足速加法奖励。
- frame `1160--1340` 内按每只脚独立接触状态划分 pre-contact、touchdown 和 stable-contact。
- pre-contact 根据到 target frame 1280 的剩余时间计算期望速度并跟踪；最大期望速度 `0.45 m/s`。
- touchdown 使用“位置得分 × 低速得分”的乘法门，禁止良好位置补偿过高接触速度。
- touchdown 后 `0.12 s` 进入稳定接触阶段，只奖励低速且接近目标的双脚支撑。
- 新项权重 `0.14`；保持 v54 有限记忆安全 CMDP、148 维 actor、固定几何和 teacher 不变。

## 训练曲线

- mean reward：`6.6024 -> -2.3074`，峰值 `8.1576 @ 92151`，最低 `-7.8078 @ 92153`。
- mean episode length：`22.0 -> 98.92`。
- policy KL：`4.194e-4 -> 5.602e-4`；teacher KL：`2.936e-5 -> 8.188e-5`。
- value loss：`12.387 -> 2.169`；surrogate loss：`0.000973 -> 0.001941`。
- cost-value loss：`3.177 -> 0.479`；constraint error：`0.04586 -> -0.00093`。
- contact-time reward 峰值 `0.002071 @ 92154`，最终 `7.50e-5`。
- 活动率峰值 `95.83% @ 92153`；touchdown fraction 峰值 `43.75% @ 92153`；stable-contact fraction 峰值 `72.22% @ 92154`，说明三段门控均实际执行。
- 位置误差最低 `0.437 @ 92153` 后最终回升到 `2.696`，足速最终升至 `0.597`。训练采样仍没有学到稳定的终段路线收敛。

## 失败原因与下一步

1. 接触前期望速度完全由当前位置到固定目标的剩余时间计算，且 touchdown/stable 阶段偏好低速。策略可以通过提前进入保守低速状态获得较稳定接触，却不必修正累计路线误差。
2. 新项的绝对权重仍小，且训练只有六次更新；它能改变局部接触形态，但不足以在受保护 teacher 附近稳定修正终段前向位移。
3. 直接提高该项权重可能重复 v49 的制动崩溃，因此不能粗暴放大。

v57 应保留相同接触相位和乘法 touchdown 门，只在 pre-contact 期望速度加入受限的最小前向进度分量，并把目标限制在最后一级到落地的短窗口；稳定接触阶段不施加前进奖励。继续从受保护基线 warm-start，不从 v56 候选继续训练。
