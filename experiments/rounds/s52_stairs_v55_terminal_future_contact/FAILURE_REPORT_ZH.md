# S52 v55 TerminalFutureContact 短预检失败报告

## 结论

v55 的 `32x2` 冒烟和 `128x6` 短预检均正常结束，没有 Traceback、NaN、OOM 或 GPU 训练故障。固定 `seed=131` 下，受保护基线和五个候选都完成上楼、平台、四级正向下楼和落地，首次周期均为零重置；但没有候选同时通过终点路线、同源刚体净空、滑移和冲击门，因此不启动正式长训练，不替换受保护的 `model_92150.pt`。

## 本轮改动

- 从受保护 S52 `model_92150.pt` warm-start，重置优化器，保持 27 维动作和 148 维 actor 观测不变。
- 继承 v54 的归一化有限记忆 clearance/impact CMDP，不延长风险记忆窗口。
- 在 frame `1190--1340` 加入未来双脚终点接触残差；目标来自参考动作 frame 1340 的左右脚位置。
- 权重为 `0.20`，位置占 `75%`、足速占 `25%`，并按剩余接触时间使用平方进度渐强，避免过早侵入下降摆腿阶段。
- 前向、横向、高度标准差分别为 `0.10/0.07/0.04 m`，足速标准差为 `0.12 m/s`。

## 训练曲线

- mean reward：`6.6024 -> -2.3128`，峰值 `8.1576 @ 92151`，最低 `-7.8100 @ 92153`。
- mean episode length：`22.0 -> 98.92`。
- policy KL：`4.194e-4 -> 5.602e-4`；teacher KL：`2.936e-5 -> 8.188e-5`。
- value loss：`12.385 -> 2.172`；surrogate loss：`0.000972 -> 0.001940`。
- cost-value loss：`3.177 -> 0.479`；constraint error：`0.04586 -> -0.00093`。
- future-contact 奖励峰值只有 `0.001587 @ 92154`，最终 `8.18e-7`；活动率峰值 `81.94% @ 92154`，但不同更新采样阶段差异很大。
- 终点接触位置误差在记录更新中从 `3.194` 最低降至 `0.426 @ 92153`，最终又回到 `2.683`；终段足速指标最终升至 `0.597`。这说明目标被看见，但策略没有形成稳定的接触减速。

## 失败原因与下一步

1. future-contact 项虽然使用了未来接触位置，但仍是奖励端的瞬时状态评分，没有显式表达“何时接触”和“接触前必须减速”。
2. 终点位置奖励的信用出现得很晚，且位置和速度得分相加允许策略用较好的位置掩盖过高落脚速度，最终表现为路线略有改善但冲击上升。
3. 原有 `scheduled_future_foothold_xy` 已覆盖楼梯摆脚段；继续重复增加同类位置项会造成目标重复，而不会解决终末接触时序。

下一版应保持 v54 的局部安全 cost 与受保护 teacher，只在最后一次落地接触前后建立互斥的 contact-time phase：接触前奖励足端向目标收敛并降低法向/水平速度，接触后短窗口奖励双脚稳定支撑；使用乘法或门控防止位置得分补偿高速冲击。仍不改变 actor 维度，不加入几何或材质随机化。
