# Kuavo S53 左脚先行逐级并步下楼训练记录

更新时间：2026-08-20

## 1. 本轮目标

下楼动作改为严格的 step-to 顺序：

1. 右脚支撑，左脚落到下一级台阶。
2. 左脚落稳后成为支撑脚。
3. 右脚移动到与左脚相同一级、相同前后定位点。
4. 双脚位置和机器人速度连续稳定后，参考轨迹才允许进入下一级。

当前阶段所有定位坐标固定，不加入坐标扰动。后续只有在四级定位门稳定通过后，才逐步加入小范围位置、质量、摩擦和控制延迟随机化。

## 3. 状态门条件

训练命令类型为 `StepToGatedMotionCommand`。到达每个门控帧后，同时满足以下条件并连续保持 10 个控制周期，轨迹才继续：

- 左右脚相对各自固定目标的最大位置误差不超过 0.035 m。
- 左右脚最大线速度不超过 0.08 m/s。
- 骨盆线速度不超过 0.08 m/s。
- 骨盆角速度不超过 0.25 rad/s。

门未通过时，参考帧冻结；策略不能依靠时间自动跳到下一台阶。

## 4. 奖励约束

在原组合模型奖励上新增或加强：

- 每级双脚固定世界坐标定位奖励。
- 左右脚同级、同前后位置奖励。
- 双脚门脚速和骨盆稳定惩罚。
- 左脚摆动时右脚的位置与速度约束。
- 右脚并步时左脚的位置与速度约束。
- 左脚后蹬速度强惩罚，右脚后退速度辅助惩罚。
- 摆动脚提前接触、支撑脚滑动和净空不足惩罚。
- 超过 850 N 的下楼落地冲击惩罚。

## 23. 上下楼梯强化学习项目与方法总览

### 23.1 调研范围与当前问题

本节整理截至 `2026-08-23` 能公开核验、且对双足/人形机器人上下楼梯直接相关的代表性项目。这里的“所有”指本轮检索到的公开论文、项目页和代码项目，不代表封闭项目或尚未公开工作的穷尽列表。近期论文仍可能处于预印本或匿名评审阶段，具体数值应以作者后续版本为准。

当前任务的关键几何为：踏面长 `0.28 m`、宽 `1.5 m`、级高 `0.13 m`，四级上楼后连接 `1.0 m x 1.5 m x 0.52 m` 平台，再正向下四级楼梯。S53 脚掌长度约 `0.228-0.24 m`，纵向理论余量只有约 `0.04-0.052 m`。这意味着平均分到脚尖和脚跟后，每侧可用余量只有约 `0.02-0.026 m`；任何脚踝目标误差、脚掌俯仰、状态估计漂移或碰撞体误差都可能导致提前撞突缘或半脚悬空。

各项目反复处理的共性难点如下：

1. **离散接触与探索稀疏**：楼梯不是连续斜坡，策略需要同时学习抬脚、越缘、落脚、换支撑和恢复平衡；只用速度奖励很容易停在平台、滑下楼梯或撞到突缘。
2. **接触前风险不可由终态奖励替代**：脚最终到达正确踏面，不代表中途没有扫过突缘。只在碰撞后处罚会产生稀疏、滞后的学习信号。
3. **窄踏面的目标冲突**：脚离前方突缘越远，越可能靠近后方边缘；碰撞安全和完整脚掌支撑必须联合优化，不能无限增大单侧安全距离。
4. **摆脚位置不足以描述安全轨迹**：脚掌是有长度和姿态的刚体。脚踝点轨迹安全时，脚尖、脚跟或脚底角点仍可能碰撞，必须约束扫掠体积和脚掌方向。
5. **相位、接触与地形耦合**：固定时钟能形成周期步态，但楼梯需要根据实际接触、落脚稳定性和地形变化调节相位或步频。
6. **局部奖励与完整任务冲突**：过强的突缘惩罚、硬门或教师约束会让“留在平台”成为局部最优；只看训练批次均值又会掩盖完整下楼阶段的失败。
7. **感知和 sim2real**：深度盲区、楼梯边缘稀疏、点云鬼影、基座定位漂移、延迟、摩擦和执行器误差都会把厘米级安全余量耗尽。

### 23.2 直接相关项目

#### 1. Mind Your Steps：三维落脚点跟踪

- 项目/论文：[Mind Your Steps](https://montenegroalessandro.github.io/mind-your-steps/)；[arXiv:2606.08253](https://arxiv.org/abs/2606.08253)。
- 核心接口不是速度命令，而是左右脚下一目标的三维位置和偏航角；目标表示在当前支撑脚坐标系中，因此整个摆动期保持不变，减小基座定位误差和目标抖动。
- Actor 输入本体状态、上一动作、步态相位和落脚目标，Critic 使用额外真值；策略输出关节位置目标，由低层 PD 执行。
- 奖励将摆动脚的 `xy`、高度和偏航误差分开，用不同核宽度跟踪；触地瞬间的落脚精度在后续支撑期保持为奖励，避免只在单帧触地时产生信号。
- 使用摆动窗口离地奖励和膝部高度单边奖励，后者直接缓解脚/膝无法越过障碍的问题；先在平地训练，再扩展到随机三维落脚点和移动支撑面。
- 对当前任务的启示：使用“当前支撑脚帧中的未来两个落脚点”，并把目标设在经脚掌尺寸腐蚀后的踏面安全区；但其公开楼梯最短踏面为 `0.30 m`，当前 `0.28 m` 更苛刻，不能只复制落脚点奖励，必须叠加接触前突缘约束。

#### 2. Unsafe Stepping Penalty：接触前密集安全惩罚

- 论文：[Omnidirectional Humanoid Locomotion on Stairs via Unsafe Stepping Penalty and Sparse LiDAR Elevation Mapping](https://arxiv.org/abs/2603.07928)。
- 将危险落脚拆成两类：脚沿运动方向撞竖直突缘，以及落在边缘导致超过一半脚底悬空。
- 突缘项在脚速度方向的 `30 deg` 锥形区域内查找最近障碍，惩罚随接近速度和距离连续增大；因此在真正接触前就有梯度，不依赖碰撞事件。
- 边缘项在脚底局部高度图上用 Sobel 提取边缘，并按脚到地面的垂直距离渐进启用；上楼和下楼根据地形梯度与命令方向修正符号。
- 突缘碰撞和边缘悬空采用两个权重联合平衡，论文特别指出窄踏面上二者会互相竞争；训练使用 10 级课程，踏面深度覆盖 `0.25-0.60 m`、级高覆盖 `0-0.23 m`。
- sim2real 使用稀疏 LiDAR 滚动高度图、时间置信度衰减、基座下方保护区和边缘引导重建，避免脚下盲区的历史楼梯信息被清除。
- 对当前任务的启示：这是最直接针对“双脚提前碰突缘”的奖励。应以脚掌各角点/前缘的速度和最近突缘向量计算连续风险，不得在接触力超过阈值后关闭；同时必须保留后缘支撑安全项，不能把目标一味向踏面前方或后方推。

#### 3. TACT-ful：地形可通行性、DCM 与带方向的摆脚轨迹

- 项目页：[TACT-ful](https://fai-rl-tech.github.io/tact-locomotion.github.io/)。该工作目前项目页标注为匿名评审，论文和代码尚未正式公开，以下内容以项目页为准。
- 用平整度 `Q`、坡度 `E`、速度相关高度可达性 `M` 和前进/爬升收益构成多通道地形代价，既驱动 GPU 并行 DCM 落脚规划，也形成密集地形可通行性奖励。
- 摆脚采用二次 Bezier 曲线。上台阶时顶点向较高端偏移，避免过早下降撞竖面；下台阶时顶点向起点偏移，先延长水平前送，再下降，以降低落地冲击角。
- 不只跟踪脚的位置，还用 Bezier 切线约束脚掌方向。越过突缘和落到踏面使用不同相位窗口，其余阶段不强行约束姿态，避免过度限制策略。
- 通过虚拟载荷作用点注入力和力矩，并把刚性骨盆高度/躯干姿态目标改成载荷相关柔顺目标，为带负载 sim2real 提供基础。
- 对当前任务的启示：v9 的 Bezier 包络应进一步改为“脚掌刚体轨迹”，让脚尖、脚跟、左右角点共同跟踪安全走廊；下楼顶点不能仅抬高，还应显式延长水平前送，姿态约束只在越缘窗口开启。

#### 4. T-GMP：地形条件自然运动先验

- 项目页：[T-GMP](https://t-gmp.github.io/T-GMP/)。
- 先由特权专家策略和人体动作捕捉收集“状态-地形”配对数据，再用条件 VAE 学习以高度图为条件的动作潜空间。
- 统一 RL 策略通过地形条件判别器获得自然动作先验，并增加 Foothold Penalty；同一策略可在平地、楼梯、斜坡、横梁和沟槽间平滑切换动作风格。
- 地形条件很重要：策略会在楼梯/斜坡降低质心、在窄梁或跨沟时展开手臂，而不是把同一种平地步态硬套到所有地形。
- 对当前任务的启示：自然动作先验应负责全身协调和姿态正则，不应在突缘窗口强制复制 `model_113994.pt` 或其他教师的碰撞轨迹。腿部教师/判别器权重应在高风险摆脚窗口衰减，由几何安全奖励优先决定局部脚轨迹。
- 限制：公开页没有完整 CVAE、专家数据、判别器权重和 Foothold Penalty 实现；当前 v6-v8 只能称为工程代理，不能写成完整复现。

#### 5. FastStair：规划器引导与分阶段专家融合

- 论文：[FastStair](https://arxiv.org/abs/2601.10365)。重点是高速上楼，但其稳定落脚与课程方法对下楼同样有参考价值。
- 用局部高度图和 Sobel 梯度寻找平坦接触区，再用与脚掌尺寸一致的卷积核评估完整足底是否可支撑。
- 将变高度倒立摆的 DCM 落脚优化改写为 GPU 并行离散搜索，使大量并行 RL 环境能使用动力学可行落脚点作为强引导。
- 第一阶段以高权重落脚跟踪训练安全基础策略；第二阶段按速度重加权，分别训练低速和高速专家；第三阶段用 LoRA 合并专家并全速域微调，避免直接切换策略造成动作不连续。
- 使用步态时钟、非对称 Actor-Critic 和瞬时摆脚目标；摆脚参考由起点、顶点和终点关键点构成。
- 对当前任务的启示：先把固定 `0.28/0.13 m` 楼梯上的低速安全下楼练好，再训练更快的平台/上楼专家；不要在一个阶段同时追求突缘安全、速度和大随机化。DCM/捕获点可作为 Critic 特权量和落脚可行性奖励，不必直接进入部署 Actor。

#### 6. LearningHumanoidWalking：未来两个有向落脚点

- 论文：[Learning Bipedal Walking on Planned Footsteps](https://arxiv.org/abs/2207.12644)；[开源代码](https://github.com/rohanpsingh/LearningHumanoidWalking)。
- 单一策略输入未来两个脚步的相对位置/方向、步态时钟和机器人状态，可完成前后走、侧走、转向、站立以及上下楼。
- 程序生成脚步序列，并按地形复杂度做课程学习；不依赖参考动作或预训练权重，减少教师错误轨迹带来的上限。
- 40 Hz 策略输出关节位置增量，低层 1 kHz PD 控制；周期奖励协调支撑期足底力和摆动期脚速，并使用动作历史/平滑项提高连续性。
- 对当前任务的启示：平台到下楼的切换应由未来两个落脚点和相位描述，而不是仅靠绝对时间或单个固定门；第二个未来脚步让策略在左脚下一级时提前知道右脚并步位置。

#### 7. Blind Bipedal Stair Traversal：盲走、记忆与强随机化

- 论文：[Blind Bipedal Stair Traversal via Sim-to-Real Reinforcement Learning](https://arxiv.org/abs/2105.08328)。
- Cassie 仅使用本体感知和循环策略，在随机楼梯地形上训练；核心改动不是堆叠楼梯专用奖励，而是把楼梯几何随机化加入训练，让策略通过历史状态推断不可见接触和台阶。
- 使用相位化足底力/脚速奖励：摆动期抑制接触力，支撑期抑制脚速；同时约束速度、方向、动作平滑、能耗和骨盆摆动。
- 随机化质量、阻尼、摩擦、编码器偏置、控制执行频率/延迟等，循环记忆处理部分可观测性，形成误踩后的恢复能力。
- 对当前任务的启示：在固定几何已经稳定后，可加入小范围踏面/级高、摩擦、延迟和状态噪声随机化，并考虑 GRU/LSTM 或短历史编码；不能在当前尚未解决突缘碰撞时提前用大范围随机化稀释问题。

#### 8. GA-PHL：脚下视野与可调步频

- 项目页：[GA-PHL](https://ga-phl.github.io/)；[arXiv:2512.07464](https://arxiv.org/abs/2512.07464)。
- 在基座下方安装朝下深度相机，直接观察双脚附近支撑区；紧凑 U-Net 以控制频率重建稠密自中心高度图，缓解前视相机看不到脚下的问题。
- 统一策略同时输出关节目标和全局步态频率/相位信号，使步频、触地时刻、姿态和局部地形联合调整，而不是使用固定时钟。
- 采用单阶段连续 teacher-student 训练，展示了长楼梯、前后向上下楼和跨沟。
- 对当前任务的启示：固定相位是当前可控基线，但最终应让策略在“脚已越缘且落地可信”时减速相位，在稳定支撑后再推进；感知版本优先覆盖脚下与下一踏面，而不是只看前方远处。

#### 9. RPL：多深度相机教师蒸馏

- 项目页：[RPL](https://rpl-humanoid.github.io/)；[论文 PDF](https://rpl-humanoid.github.io/static/rpl.pdf)。
- 第一阶段分别训练使用特权真值高度图的地形专家；第二阶段把专家蒸馏到使用多路深度图和时序 Transformer 的统一学生策略。
- 训练中模拟深度噪声、延迟、掉帧和遮挡；根据速度命令调节深度特征尺度，并随机遮掉侧向视野，增强未知楼梯宽度和观测不完整时的鲁棒性。
- 使用 GPU 光线投射同时考虑机器人和地形网格，避免把自身肢体误当作地形；演示双向上下楼和不同踏面长度。
- 对当前任务的启示：先用 Isaac 真值高度场训练几何安全教师，再蒸馏到真实深度输入；当前回放记录应同步保存真值高度图、模拟深度图、落脚目标和安全代价，给后续蒸馏留下数据接口。

#### 10. Now You See That：原始像素端到端与多地形冲突分解

- 项目页：[Now You See That](https://hellod035.github.io/Now_You_See_That/)。
- 先训练使用高度扫描的特权教师，再将原始深度/双目视觉学生部署到真实机器人。
- 用多个 Critic 和多个地形条件判别器分解平地、楼梯、斜坡等互相冲突的价值与动作先验，避免单一全局奖励平均掉下楼局部失败。
- 视觉蒸馏包含潜变量对齐和对噪声不敏感的辅助任务；深度仿真加入双目空洞、随距离变化的噪声和标定误差。
- 对当前任务的启示：奖励曲线必须按“上楼/平台/第 1-4 级下楼”分阶段统计；训练采样和价值估计也应提高下降突缘窗口权重，不能只看完整 episode 的总奖励均值。

#### 11. PIM：感知内部模型与短期预测

- 项目页：[PIM](https://junfeng-long.github.io/PIM/)；[arXiv:2411.14386](https://arxiv.org/abs/2411.14386)。
- 维护自中心局部高度图，并由本体历史和地形感知预测下一时刻速度及潜在状态；训练结合回归和对比学习，让策略获得对隐含接触/地形变化的短期预测能力。
- Actor 只用部署可得观测，Critic 使用额外特权状态；训练采用动作课程，先冻结较次要的手臂/腰部自由度，再逐步开放全身控制。
- sim2real 通过 LiDAR 构建重力对齐高度图，并过滤机体点云。
- 对当前任务的启示：增加“下一控制周期脚掌扫掠到突缘的预测距离”比只看当前距离更早给出风险信号；动作课程可先训练双腿和骨盆安全下楼，再逐步恢复手臂自然摆动。

#### 12. Explicit Stair Geometry Conditioning：显式楼梯参数

- 论文：[Explicit Stair Geometry Conditioning for Robust Humanoid Locomotion](https://arxiv.org/abs/2605.09944)。
- 不直接把高维原始高度图作为唯一输入，而向策略显式提供地形状态（上楼/下楼/平地）、级高、踏面深度和楼梯偏航角。
- 训练中程序随机化级高、踏面、朝向和楼梯前后平地，策略据此自适应摆脚净空和身体高度；论文报告显式几何比盲策略和纯高度图基线收敛更快、成功率更高。
- 对当前任务的启示：当前固定场景可先把 `[phase_type, riser_height=0.13, tread_depth=0.28, stair_yaw]` 作为命令/观测，避免让网络从参考帧号间接猜测任务阶段；后续再把这些参数替换为感知估计值并加小噪声。

#### 13. PRIOR：参考步态先验与地形自适应落脚

- 论文：[PRIOR](https://arxiv.org/abs/2603.18979)。
- 使用参数化步态生成器提供来自动作捕捉的稳定参考，不需要对抗训练；GRU 状态估计器从自中心深度图自监督重建高度图。
- 地形自适应落脚奖励把脚引向可通行区域，参考步态、地形估计和落脚安全三个组件互补。
- 对当前任务的启示：将自然步态参考参数化成相位、步长、抬脚高度和脚掌角度，不逐帧锁定关节；GRU 估计器可在真实深度短暂丢失时利用历史保持下一踏面几何。

#### 14. VideoMimic：从视频获得全身动作先验

- 项目页：[VideoMimic](https://videomimic.github.io/)；[arXiv:2505.03729](https://arxiv.org/abs/2505.03729)。
- 从单目视频重建人体和场景，重定向到机器人，再训练场景条件全身控制策略；覆盖上下楼、坐下和复杂场景交互。
- 其价值在于提供自然下楼的质心、骨盆、手臂和腿部协调先验，而不是替代机器人真实碰撞几何。
- 对当前任务的启示：可把人工/视频下楼动作转成低权重姿态或潜空间先验，但落脚位置、扫掠突缘和接触力必须由 Isaac 物理与机器人脚掌碰撞体修正；视频重建误差不能直接作为硬教师。

#### 15. PolygMap：KUAVO 楼梯感知与安全区域规划

- 论文：[PolygMap](https://arxiv.org/abs/2510.12346)。这不是纯 RL 项目，但机器人平台和楼梯任务与当前工作高度相关。
- 融合 LiDAR、RGB-D、IMU 和机器人运动学进行低漂移状态估计，实时提取楼梯踏面多边形语义地图。
- 使用滤波、平面拟合和分层腐蚀从踏面多边形得到远离边缘的安全落脚区域，再进行脚步和全身轨迹规划；作者在 KUAVO 上验证室内外楼梯。
- 对当前任务的启示：训练中的固定落脚点不应手工凭脚踝中心猜测，而应由“踏面多边形减去旋转后脚掌多边形和安全边距”的几何腐蚀自动计算；真实部署则用感知多边形更新目标。

### 23.3 补充方法与基础组件

#### 16. Humanoid Motion Generation in a World of Stairs

- 论文：[Humanoid Motion Generation in a World of Stairs](https://iris.uniroma1.it/retrieve/7a87a3fe-a22f-4ba2-aa5a-0228515f1cfd/Cipriano_Humanoid_2023.pdf)。该工作属于模型规划/MPC，而非端到端 RL。
- 随机化脚步规划器显式检查踏面、边缘和可达性，并由三维稳定 MPC 生成动态可行全身运动；支持已知地图离线规划和传感器驱动在线规划。
- 对当前任务的启示：规划器可作为落脚目标教师、DCM/稳定性标签和安全回退，不必替代 RL；RL 负责模型误差和接触恢复，规划器负责不把探索引向明显不可行位置。

#### 17. Fourier/周期步态与规划脚步

- 论文：[Learning 3D Bipedal Walking with Planned Footsteps and Fourier Series Periodic Gait Planning](https://pmc.ncbi.nlm.nih.gov/articles/PMC9962549/)。
- 用有向落脚目标和 Fourier 周期函数表达支撑/摆动节律，降低手写离散相位切换产生的不连续。
- 对当前任务的启示：可把固定二值 swing/stance mask 改为平滑相位权重，使突缘、抬脚、落地和双支撑奖励连续淡入淡出，减少相邻奖励在切换帧互相冲突。

#### 18. Hybrid RL and Heuristics

- 论文：[Hybrid Bipedal Locomotion Based on Reinforcement Learning and Heuristics](https://pmc.ncbi.nlm.nih.gov/articles/PMC9611364/)。
- 启发式摆脚轨迹负责明确的脚端几何，RL 负责支撑腿/全身稳定；接触事件触发相位切换，降低纯时钟与真实触地不同步的问题。
- 对当前任务的启示：可先由可解释 Bezier/多项式给出安全脚掌参考，再让策略输出残差；触地后仅在足底支撑质量满足时切换相位，但不使用会永久阻塞任务进度的硬门。

#### 19. Selective AMP 多步态训练

- 论文：[Multi-Gait Learning with Selective Adversarial Motion Prior](https://arxiv.org/abs/2604.19102)。
- 只对步行、鹅步和爬楼等周期、稳定性敏感动作启用 AMP，对跑跳等高动态动作关闭，说明动作先验应按技能选择，而不是全局固定。
- 对当前任务的启示：AMP/T-GMP 先验可用于上楼、平台和稳定下楼的一般姿态；在脚掌接近突缘的高风险窗口应降低先验权重，让碰撞安全与落脚几何拥有更高优先级。

### 23.4 方法对照与采用顺序

| 问题 | 最直接的方法来源 | 当前固定场景 | 固定场景稳定后 | sim2real 阶段 |
| --- | --- | --- | --- | --- |
| 提前撞竖直突缘 | Unsafe Stepping、TACT-ful、PIM | 连续预测距离、速度方向、脚掌扫掠体积、Bezier 切线姿态 | 小范围级高/踏面随机化 | 由稀疏 LiDAR/深度高度图计算突缘 |
| 半脚悬空或踩边 | Unsafe Stepping、FastStair、PolygMap | 踏面多边形按脚掌腐蚀、完整脚底采样 | 随机脚掌朝向和边缘误差 | 感知多边形、置信度与保守边距 |
| 停在平台不下楼 | LearningHumanoidWalking、Mind Your Steps | 未来两个落脚点、进度奖励、软相位切换 | 随机平台到首级距离 | 感知触发任务阶段，不依赖绝对坐标 |
| 固定时钟与接触不同步 | GA-PHL、Hybrid RL | 接触可信度调节相位推进 | 学习步频/相位残差 | 估计延迟和接触噪声随机化 |
| 全局教师复制碰撞 | T-GMP、VideoMimic、Selective AMP | 突缘窗口降低腿部先验，只保留全身协调 | 地形条件潜空间先验 | 真实视频/专家数据再训练先验 |
| 训练均值掩盖下楼失败 | Now You See That、RPL | 分阶段采样、分阶段 Critic/指标 | 多几何、多 seed 评估 | 真实感知失效模式单独评估 |
| 动力学可行落脚 | FastStair、World of Stairs | DCM/捕获点作为特权标签或软奖励 | 增加速度专家 | 规划器作为安全回退 |
| 看不到脚下楼梯 | GA-PHL、RPL、PIM | 先保留真值高度图数据接口 | 教师-学生蒸馏 | 朝下相机或 LiDAR 滚动图 |
| 尺寸变化泛化 | Blind Cassie、Explicit Geometry | 暂不随机化 | 显式输入级高/踏面并逐级课程 | 加摩擦、延迟、质量和感知噪声 |

采用优先级：

1. **P0，当前立即采用**：Mind Your Steps 的未来落脚点、Unsafe Stepping 的接触前密集惩罚、TACT-ful 的下楼 Bezier 水平前送与切线姿态、PolygMap 的脚掌腐蚀安全区、分阶段训练/评估。
2. **P1，固定几何能稳定通关后采用**：显式楼梯几何条件、相位/步频残差、轻量 DCM 可行性奖励、小范围踏面/级高/摩擦/延迟课程。
3. **P2，准备真实部署时采用**：脚下深度或 LiDAR 高度图、特权教师到视觉学生蒸馏、时序 GRU/Transformer、点云自遮挡和感知空洞模拟。
4. **P3，动作自然度与多任务扩展**：正式 T-GMP CVAE、VideoMimic 数据、地形条件 AMP、多速度专家/LoRA；这些不能先于几何安全和完整任务成功率。

### 23.5 针对当前 S53 的推荐奖励结构

以下是由上述项目综合得到的工程方案，不是任何单篇论文的原式复现。所有项都应记录原始未加权统计量，避免权重改变后无法比较。

```text
R_total = R_task + R_foothold + R_swing_path + R_support
          + R_balance + R_style + R_smooth + R_safety
```

1. **任务进度 `R_task`**：奖励根节点沿完整路线的有符号进度和每个真实踏面首次稳定接触；平台停留超过合理窗口后不再持续给存活奖励。终点奖励只有在双脚实际接触地面、根节点高度回落和无重置时发放。
2. **未来落脚点 `R_foothold`**：左右脚各输入未来两个 `(x,y,z,yaw)` 目标，表示在当前支撑脚坐标系；摆动期分别跟踪 `xy/z/yaw`，触地后保留触地精度。落脚目标由踏面多边形减去脚掌多边形与 `10-15 mm` 初始边距自动生成。
3. **脚掌扫掠 `R_swing_path`**：对脚尖、脚跟和四个角点预测一小段时间后的轨迹，计算其到运动方向 `30 deg` 锥内最近突缘的距离。风险应随朝向突缘的速度和距离连续增加，越缘前后始终生效，不能因 `contact_force > 40 N` 而关闭。
4. **Bezier 位置与姿态**：下楼时顶点向离地起点侧偏，先完成水平前送再下降；仅在突缘窗口跟踪脚掌切线/俯仰，落地前逐渐回到接近踏面平行。位置和姿态使用软核，不设一步不满足就永久阻塞的硬门。
5. **完整支撑 `R_support`**：触地前按脚底局部高度图边缘连续处罚；触地后检查全部脚底采样点是否位于同一踏面、支撑面积比例、CoP/压力中心边距、脚速和角速度。突缘安全和边缘安全使用独立权重并联合调参。
6. **支撑腿稳定**：摆动脚越缘时奖励对侧脚低滑移、低角速度和稳定接触；触地换支撑采用平滑权重，而不是立即交换二值角色。允许短双支撑吸收冲击。
7. **冲击与滑动**：惩罚触地法向冲量、峰值接触力、切向脚速和接触后脚掌角速度；冲击统计使用分位数/峰值，避免平均值掩盖单次危险落地。
8. **姿态与动作先验 `R_style`**：保留骨盆、躯干和手臂协调；腿部教师或 AMP 权重在突缘风险窗口按 `risk` 衰减，例如 `w_prior_leg = w0 * (1 - risk)`，避免危险参考压过安全项。
9. **平滑与可部署性 `R_smooth`**：动作一阶/二阶变化、关节速度/加速度、力矩、功率和关节限位；策略仍输出 PD 目标，后续加入控制延迟和增益随机化。
10. **终止 `R_safety`**：跌倒、非足部危险碰撞和明显越界终止；脚尖轻触突缘应产生强密集处罚和事件计数，但不宜立即终止，否则策略只学会停步规避。

推荐的课程顺序：

```text
阶段 A：固定 0.28/0.13 m，低速，真值地形，无扰动；只要求完整通关和零突缘碰撞
阶段 B：保持固定几何，收紧脚掌边距、滑动、冲击和连续多 seed 成功率
阶段 C：级高 +/-5 mm、踏面 +/-10 mm、起点/yaw 小扰动，显式输入楼梯参数
阶段 D：摩擦、质量、PD、延迟、观测噪声和轻外力随机化
阶段 E：真值高度图教师蒸馏到朝下深度/LiDAR 时序学生
阶段 F：加入自然动作先验、速度专家和更大范围地形泛化
```

### 23.6 必须避免再次出现的奖励错误

1. 不得只奖励脚踝最终到点而忽略脚掌中途扫过突缘。
2. 不得在提前接触发生后关闭突缘惩罚；接触事件应让违规更强，而不是让奖励失明。
3. 不得只把落脚点向单侧移动来解决碰撞；`0.28 m` 踏面需要同时核算脚尖和脚跟余量。
4. 不得用固定帧号替代接触和地形条件；参考相位可以初始化时序，但任务推进必须由物理状态确认。
5. 不得让固定门成为进度的唯一入口。稳定门可发奖励或调节相位，但策略偶发未满足时仍需获得朝正确动作改进的连续梯度。
6. 不得让教师/AMP 在危险窗口高权重复制旧碰撞动作；先验只负责自然性，几何安全拥有更高优先级。
7. 不得以训练批次 `toe_safe_fraction` 代替完整路线验收；必须按每一级、每只脚统计最小突缘距离、碰撞帧、完整支撑、滑动和冲击。
8. 不得默认编号最大的 checkpoint 最好；应在奖励峰值、退化拐点和末尾抽取多个模型，用相同多 seed 真实物理 rollout 排序。
9. 不得在固定场景仍不稳定时加入大范围坐标/地形随机化或复杂视觉输入。
10. 不得把无界面关节动画当作物理验收；正式结论必须来自 Isaac/PhysX rollout，视频只负责忠实呈现记录数据。

### 23.7 验收指标

每个候选模型至少运行 `10` 个固定场景 seed；固定场景连续成功前不进入随机化阶段。报告均值的同时必须报告每级、每脚和最坏值。

- 完整任务成功率：完成上楼、平台和四级正向下楼，固定场景目标为 `10/10`。
- 突缘碰撞：左右脚、每一级的碰撞帧数和冲量；固定场景目标为 `0`。
- 接触前最小净距：脚尖、脚跟、内外侧角点分别统计；不能只看脚踝中心。
- 落脚质量：完整脚掌支撑比例、前后/左右边缘最小余量、错误踏面和跨级支撑次数。
- 支撑转换：摆动脚首次接触、稳定接触、对侧离地和双支撑持续时间，检查是否发生滑落而非走下。
- 动力学：左右脚滑动 p95、峰值法向力、落地冲量、脚掌角速度、骨盆 roll/pitch 和质心速度。
- 学习稳定性：总奖励、episode length、KL、value/surrogate loss、探索标准差、各奖励原始量和 termination 分类。
- sim2real 余量：在小范围摩擦、质量、PD、延迟和楼梯尺寸扰动下的成功率及最坏安全余量。

### 23.8 结论

当前问题不是简单地“再加大突缘惩罚”。更可靠的路线是把下楼拆成四层相互配合的约束：**未来落脚点决定去哪里，脚掌扫掠与 Bezier 切线决定怎样越过突缘，完整足底/支撑动力学决定怎样落稳，地形条件先验决定全身怎样自然协调**。只有前面三层固定场景连续通过后，才进入感知、随机化和更自然动作的 sim2real 阶段。

## 26. PredictiveSweep v10 从 model_92099 保留下楼能力并改善突缘净空

### 26.1 v8/v9 为什么没有解决问题

`model_92099.pt` 已能完成上楼、平台和四级正向下楼，且滑动和冲击明显低于后续模型。后续训练失败的主要原因不是缺少更大的惩罚权重，而是风险对象和信用分配错误：

1. v8 的连续屏障覆盖整个下降阶段，并同时作用于支撑脚和摆动脚。它没有识别当前脚正在跨越哪一道突缘，因此合法支撑、落地和下一次摆动可能同时收到冲突梯度。腿部教师权重又降到 `0.05`，策略失去原有下楼动力学后，以更高冲击换取了局部距离奖励。

3. v9 全局降低 feet position/velocity/angle 跟踪，但安全修正实际只应发生在越缘前几十毫秒。窗口外跟踪也被削弱后，原本稳定的下楼和低滑移动作一起退化。
4. v8/v9 的总奖励和 episode length 仍可通过完成参考进度提高，最坏净距、单次冲击和滑移却持续恶化。训练批次均值不能替代固定完整路线的最坏值选模。

- **Unsafe Stepping Penalty**（论文：[arXiv:2603.07928](https://arxiv.org/abs/2603.07928)）在实际碰撞前利用足端速度方向和障碍几何判断不安全落脚，把离散碰撞反馈前移为连续风险反馈。论文方法启发 v15 使用“时间到突缘”速度锥，而不是继续提高稀疏 running-min 权重。
- **TACT-ful Locomotion**（官方项目页：[TACT](https://fai-rl-tech.github.io/tact-locomotion.github.io/)）通过可调 Bézier 摆脚轨迹和足端姿态控制跨越障碍。对当前任务的工程映射是在接近突缘窗口内要求脚尖相对脚跟保持最小上翘量；这不是照搬其控制器，而是把其几何先验转成局部奖励。

### 38.4 下一方向：直接约束物理 cost

### 39.3 问题解释与 v22 方向

本轮不是“CaT 权重还不够大”。随机终止截断了危险状态后的任务回报，并显著改变训练状态
分布；策略可以通过更早终止避开后续代价。Play 验收关闭人为终止后，这个训练捷径消失，
真实最坏净空便暴露出明显退化。继续增大终止概率会进一步鼓励不下楼，降低概率则又变回
过稀疏信号。

一手资料与适用结论：

- [CaT](https://arxiv.org/abs/2403.18765) 明确用违反程度映射随机终止；论文证明该方法可
  低改动接入 PPO，但本任务的长时序完整通关和毫米级短踏面尾部风险使训练/验收分布一致性
  尤其关键。
- [Evaluation of Constrained RL Algorithms for Legged Locomotion](https://arxiv.org/abs/2309.15430)
  将物理约束与任务奖励分离为 CMDP，并在腿式机器人上比较约束优化器；更适合下一版保留
  完整 episode、单独控制净空 cost 预算。
- [Safe Reinforcement Learning for Legged Locomotion](https://arxiv.org/abs/2203.02638)
  使用独立恢复策略按未来风险最小介入。迁移到 S53 的工程推断是：硬保护应作为同一物理
  定义的安全层，而不是只在训练中存在、Play 中消失的终止条件。
- [Contact-conditioned learning of locomotion policies](https://arxiv.org/abs/2408.00776)
  对双足策略输入未来接触位置和时序，并报告相对速度条件策略更好的鲁棒性；支持后续把
  左右脚接触相位和未来踏面目标显式提供给策略/critic。

v22 改为完整 episode 上的独立逐步净空 cost，由拉格朗日乘子/CMDP 约束预算更新，任务
回报不因近突缘样本被截断。若保留硬保护，只对实际碰撞深度触发，且训练与 Play 使用同一
物理定义。先做 cost 标度与预算的 `32x2`、`128` 预检，再执行同 seed 真实联评；仍不得
因平均回报或滑移改善接受最坏净空退化。

### 40.3 原因与 v23 方向

v22 暴露了“约束定义覆盖不足”而不只是“乘子太小”：训练 cost 只按参考摆腿、指定帧段和

一手资料与适用结论：

- [Evaluation of Constrained RL Algorithms for Legged Locomotion](https://arxiv.org/abs/2309.15430)
  将物理约束与任务奖励分离成 CMDP，并在腿式机器人上比较约束优化器。v23 应实现独立
  cost rollout、cost value/GAE 与拉格朗日更新，不能继续把自适应 cost 乘回普通 reward
  后称为完整 CMDP。
- [Constrained Policy Optimization](https://arxiv.org/abs/1705.10528) 直接优化任务回报并
  约束期望 cost，强调每次策略更新的近约束满足。工程上支持以真实刚体最坏净空 cost
  约束更新，而不是用 teacher KL 或平均回报代理安全。
- [Contact-conditioned learning of multi-gait locomotion policies](https://arxiv.org/abs/2408.00776)

### 41.3 问题解释与 v24 方向

v23 证明“独立 cost critic”本身不会自动保证毫米级尾部安全。当前乘子是纯积分式更新，40
轮内只从 `0.100` 到 `0.115`，策略已经先发生 overshoot；同时期望 cost 约束会平均掉 12
个关键风险步，不能直接保护 episode 内最坏一次突缘接近。`model_92140` 的共享最小距离虽
改善，但旧验收净空、冲击和 cost 频率同时变坏，也不能作为基线。

一手资料与适用结论：

- [PID Lagrangian](https://proceedings.mlr.press/v119/stooke20a/stooke20a.pdf) 指出普通
  Lagrangian 相当于积分控制，容易出现约束 overshoot 和振荡；其比例/微分项用于阻尼和
  提前响应。v24 应以 cost 超预算的比例项和变化率项更新乘子，而不是只提高固定权重。
- [Interior-point Policy Optimization](https://arxiv.org/abs/1910.09615) 用对数 barrier
  在策略更新中保持累计约束；工程上可用于把共享 cost 的安全边界放进更新目标，但必须
  保留 `model_92138` 的低漂移 trust region，避免 barrier 把策略推离可通关动作。
- [Lyapunov-based Safe Policy Optimization](https://arxiv.org/abs/1901.10031) 通过参数或
  动作投影使每次更新接近可行集。对当前任务的工程推断是：以 teacher 动作为中心，只允许
  沿 cost critic 预测不增大的方向更新危险帧动作，比期望 cost 的全 episode 平均更直接。
- [CPO](https://arxiv.org/abs/1705.10528) 关注每次策略更新的近约束满足；本轮结果再次说明
  不能只检查训练末端平均 cost，必须继续用固定 seed 的最坏净空门做逐 checkpoint 验收。

v24 采用更保守的两层方案：保留 v23 的同源刚体 cost 与独立 cost critic；把 multiplier
改为有阻尼的 PID Lagrangian，并对每个下降摆腿片段聚合 worst-step cost，防止危险步被
episode 均值稀释；同时提高 teacher trust-region 强度、缩小单轮策略漂移。先做 `32x2`
和 `128` 预检，只有旧验收净空不低于 `1.959 mm`、共享 cost 不劣于 `model_92138` 且
滑移/冲击无严重冲突时才启动正式训练。

### 42.3 方法依据与 v25 设计

- [PID Lagrangian](https://proceedings.mlr.press/v119/stooke20a/stooke20a.pdf) 明确指出
  约束数值尺度会影响控制器整定，并提出尺度不变的调参方法。工程结论是先把预算校准到
  基线同尺度分布，再调整 PID；不能继续放大不可满足的 running-min 权重。
- [Risk-Constrained RL with Percentile Risk Criteria](https://arxiv.org/abs/1512.01629)
  用 chance/CVaR 约束累计 cost，保护小概率高损失事件。工程上支持保留片段尾部风险，
  但不支持把单个最大值无衰减复制到整段所有时间步。
- [Mind Your Steps](https://montenegroalessandro.github.io/mind-your-steps/) 以未来落脚点条件化
  策略并针对短踏面精确跟踪。它支持后续显式约束整脚安全走廊，而不是只优化单一脚尖距离。

v25 将最坏片段 cost 以 `10%` 比例混回原始逐步 cost；预算设为安全基线同尺度估计
`0.0203`，并把 PID 降为 `10/0.1/2`。同时收紧 teacher trust region：学习率
`1e-7`、clip `0.003`、teacher action/ KL 系数 `12/0.5`、初始 std `0.003`。

### 43.3 下一版问题定义

- [CPO](https://arxiv.org/abs/1705.10528) 和
  [PID Lagrangian](https://proceedings.mlr.press/v119/stooke20a/stooke20a.pdf) 都要求
  约束与验收量一致；平均 cost 满足预算而最坏风险退化时，不能据此宣布可行。
- [Contact-conditioned locomotion](https://arxiv.org/abs/2408.00776) 将未来接触位置和时序

  同时约束自然动作和落脚。下一版可借鉴其“局部地形条件 + 落脚约束”，但当前先统一几何
  审计定义，不直接增加生成先验或地形随机化。

## 对应项目与下一步

- [SCPO（State-wise Constrained Policy Optimization）](https://arxiv.org/abs/2306.12594) 明确针对期望 CMDP 无法约束单状态最坏风险，使用 Maximum MDP 约束状态级最大 violation。工程上应把下降摆腿突缘 cost 本身做 state-wise/worst-step 聚合，而不是继续增大全局动作 imitation 权重。
- [ASCPO](https://arxiv.org/abs/2410.01212) 把状态级约束扩展为高概率满足，说明仅优化平均 cost 或平均 KL 不能排除低概率危险状态。固定几何阶段可先实现下降窗口 top-k / max cost，再用多 seed 验收近似高概率门。
- [Mind Your Steps](https://arxiv.org/abs/2606.08253) 直接以三维目标足位姿驱动低层策略，避免纯速度/全身 tracking 缺少明确落脚控制。工程上下一阶段应引入未来落脚点及下降足端安全走廊，而不是依赖全局 teacher action 距离代理净空。
- [Contact-conditioned learning of locomotion policies](https://arxiv.org/abs/2408.00776) 将下一接触位置和剩余时间作为策略条件，适合把每一级下楼的接触位置、时序和摆腿阶段显式化。

下一版先做更强但保守的状态尾部信任预检：将 top-tail 收窄到 1%、提高尾部系数并收紧硬投影，只验证能否保持安全基线；它仍是 SCPO 的近似，不作为最终方案。若仍失败，就停止用 action-distance 代理，转为下降摆腿窗口的同源刚体净空 max/top-k cost 与 future foothold 条件。

### 57.11 对 57.10 的进一步修正：物理 rollout 是监督集，不是 command motion

对 148 维 actor 输入逐槽探针后，57.10 中“用真实 S53 rollout 重建 command motion”的结论需要

1. `kuavoS52_model92099_stairs_retargeted_50fps.npz` 继续作为理想 command reference；
2. S53 成功物理 rollout 作为离线 SFT/蒸馏数据，提供 `(148-D observation, 27-D action)` 和实际
   接触结果，不替换 command；
3. 27 关节顺序和 148 维槽位完成同源探针后保持冻结，S52 只做动力学适配；
4. S52/S53 理想 reference 首步观测组最大差约 `0.00404`，joint velocity 最大差约 `0.00110`，
   actor 输出分布一致，说明接口映射正确。

本次还修复了一个独立资产错误：S52 构建期间曾误把 `merge_fixed_joints=False` 加到 S53 资产，
使 S53 body index 与 28-body motion 不一致并触发 CUDA 越界。该设置已从 S53 移除；S52 仍保留
自己的 30-body 拓扑。此类错误必须先做 body/joint 语义探针，不能用奖励函数掩盖。

### 57.17 v10 后的路线：实际访问状态回放与 delta action

[ASAP 官方项目](https://agile.human2humanoid.com/) 将动力学迁移拆成：源仿真 motion tracker、
目标系统轨迹采集、delta action 模型、把冻结 delta 模型并入仿真后微调原策略。其
[官方仓库](https://github.com/LeCAR-Lab/ASAP) 还明确要求 delta-action motion 文件带实际
`action` 字段。论文方法并不是在理想 reference 状态上反复放大奖励，也不是先做大范围 DR。

本项目据此作出的工程映射：

1. 保持理想 S52 retarget 为 command，不能再次用物理 rollout 替换 148 维 command 分布；
2. 从 S52 PhysX 的真实 frame-0 失败 rollout 读取 `q/qdot/base/contact/148-D obs/27-D action`，
   作为目标动力学访问状态；
3. 训练 reset 回放 frame 160--240 的实际状态，使策略看到自己到达第二次摆腿前的偏差，而不是
   被直接放到理想参考状态；
4. 在这些状态上学习小 residual/adapter；原 actor 冻结或保持严格 teacher trust；
5. 每轮以新的 frame-0 rollout 补充访问状态，形成 DAgger 式闭环；只有真实首段上楼推进才
   扩展到后续台阶、平台和下楼；
6. S52 Lab 固定参数完整通关后，才进入官方 MuJoCo 名义验收；Lab/MuJoCo 同源后再逐项开启
   质量、质心、摩擦、PD/motor strength、延迟和传感噪声的窄范围域随机化。

上述“用 S52 PhysX 当目标系统”是对 ASAP 的工程类比，不是论文直接给出的 Kuavo S52 参数。
下一版先做 actual-state replay 的只读数据/重置探针；若重置后的 `q/qdot/base/contact` 与原
rollout 不一致，禁止启动训练并先修正状态语义。

### 57.18 actual-state replay 同源探针（2026-09-01）

已在 v10 相同的 S52 Play 任务、固定 `seed=42` 下重新采集只读 `model_92099.pt` teacher
轨迹。它包含 1352 个状态、1351 个动作、29 个 S52 仿真关节、27 维策略动作、148 维观测、
根状态、30 个刚体状态和接触力；5 个周期均在首段上楼约 frame 264 后失败重置。因此 v11 的
目标域数据来自原 teacher，而不是被否决的 v10 最终策略。

新增只读探针 `scripts/reinforcement_learning/rsl_rl/probe_s52_actual_state_replay.py`，在
frame `160/180/207/220/240` 分别执行“写回真实状态 -> 重建 command/上一动作 -> 执行原下一
动作 -> 与原 rollout 下一帧比较”。结果如下：

- 写回后 148 维观测最大绝对误差不超过 `7.2e-7`；
- 写回后全身刚体位置最大误差不超过 `9.6e-7 m`，29 关节位置逐项一致；
- 单步后刚体位置误差仍约 `1.3e-5--1.0e-4 m`，说明根状态和关节语义正确；
- 单步观测误差为 `0.013--0.443`，主要来自 joint velocity；
- 承重帧接触力最大差约 `43.5 N @ 207`、`204.3 N @ 240`。NPZ 无法保存 PhysX 接触求解器
  warm-start/cache，这是接触瞬间单步差异的主要工程解释。

结论：actual-state reset 可以准确重建策略所见状态，但不能在冲击帧直接假设接触求解器历史
也被复原。下一版只能从关键摆腿前 `7--62` 步的真实访问状态开始，让接触在前置走廊内自然
重建；不得直接从 frame 207/240 的承重瞬间硬切入。
